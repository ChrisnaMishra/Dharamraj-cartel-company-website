# Contributing to Dharamraj Cartel

Thank you for helping improve the Dharamraj Cartel website. Reports, practical suggestions, accessibility feedback, mobile testing, copy corrections and code improvements are welcome.

## Before changing code

1. Search existing Issues and Pull Requests to avoid duplicating work.
2. For major layout, brand, logo, product-catalogue or navigation changes, open an Issue first and wait for maintainer feedback.
3. Please send pull requests to the **`development`** branch, not `main`. The `main` branch is reserved for the approved public website.
4. Work in a fork and feature branch. Do not ask for or expect write access to the original repository.

## Useful contributions

- Report broken links, missing images and mobile-layout problems.
- Suggest accessibility, performance, and readability improvements.
- Improve the Store or construction catalogue without duplicating their purpose.
- Help test the enquiry-to-WhatsApp flow.
- Submit small, focused fixes with screenshots where relevant.

## Pull request checklist

- [ ] The change has a clear purpose and stays focused.
- [ ] I tested it in a browser at desktop and mobile sizes, where relevant.
- [ ] Internal links, product filters and enquiry actions still work.
- [ ] I have not added passwords, API keys, tokens, private customer data, or other secrets.
- [ ] Images, fonts and other assets are owned by me, appropriately licensed, or already approved for this project.
- [ ] I have not made unverified claims about stock, product quality, delivery, certifications, or the business.
- [ ] I included screenshots or steps to reproduce the change where useful.

## Brand and business accuracy

Please do not replace the original Dharamraj Cartel emblem, redraw the trademark, or introduce a new brand identity without approval. Product photos shown as examples must not imply that an item is in stock. Rates, availability, warranties, registration details, and supplier claims must be confirmed by the owner.

## How changes are accepted

Opening a pull request does not mean it will automatically be accepted. The maintainer will review it, may ask for changes, and decides whether and when to merge it. Community changes should be tested on `development` before being considered for `main`.

## Licensing note

This repository does not currently include a project license. Public visibility alone is not permission to reuse the site's artwork, logo, product photos, or code elsewhere. Before accepting contributions for broad reuse, the owner should choose and publish an appropriate license and clarify contribution terms.
