# Contributing to Dharamraj Cartel

Thank you for helping improve the Dharamraj Cartel website. Reports, practical suggestions, accessibility feedback, mobile testing, copy corrections and code improvements are welcome.

## Before changing code
1. Search existing Issues and Pull Requests to avoid duplicating work.
2. For major layout, brand, logo, product catalogue or navigation changes, open an Issue first.
3. Send pull requests to the **`development`** branch, not `main`. The `main` branch is reserved for the approved public website.
4. Work in a fork and feature branch. Direct write access to the original repository is not required for a contribution.

## Useful contributions
- Report broken links, missing images and mobile-layout problems.
- Suggest accessibility, performance and readability improvements.
- Help test the retail Store and construction catalogue.
- Test product filters and enquiry-to-WhatsApp actions.
- Submit small, focused fixes with screenshots where relevant.

## Pull request checklist
- [ ] The change has a clear purpose and stays focused.
- [ ] I tested it in a browser at desktop and mobile sizes, where relevant.
- [ ] Internal links, product filters and enquiry actions still work.
- [ ] I have not added passwords, API keys, tokens, private customer data or other secrets.
- [ ] Images, fonts and other assets are owned by me, appropriately licensed, or approved for this project.
- [ ] I have not made unverified claims about stock, quality, delivery, certifications or the business.
- [ ] Screenshots or reproduction steps are included where useful.

## Brand and business accuracy
Please do not replace or redraw the original Dharamraj Cartel trademark artwork or introduce a new brand identity without approval. Example photos must not imply an item is in stock. Rates, availability, warranties, registration details and supplier claims must be confirmed by the owner.

## Review
Opening a pull request does not mean it will be accepted. The maintainer may ask for changes and decides whether and when to merge it. Community code changes should be tested on `development` before being considered for `main`.
