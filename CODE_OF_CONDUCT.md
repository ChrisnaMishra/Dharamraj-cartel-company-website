# Community Code of Conduct

Dharamraj Cartel welcomes constructive participation from people with different skill levels and backgrounds.

## Expected behaviour
- Be respectful, patient and constructive.
- Critique ideas or code, not the person.
- Explain problems clearly and give useful feedback.
- Respect the original branding and the owner's business decisions.
- Share only information you have the right to share.
- Keep customer, supplier, account and other private information out of public discussions.

## Unacceptable behaviour
- Harassment, discrimination, threats, insults or personal attacks.
- Publishing private information without permission.
- Spam, deceptive promotion or intentionally misleading product/business claims.
- Posting credentials, tokens, private customer details or sensitive vulnerability details in public Issues or Pull Requests.
- Repeatedly disrupting discussions after being asked to stop.

## Maintainer response
The maintainer may edit or remove inappropriate content, close discussions, decline contributions, or block accounts that violate this code. Security issues should be reported privately, not in a public bug report.

## Reporting a problem
For conduct concerns, contact the repository maintainer using GitHub's repository moderation tools. Do not publish private contact details or unrelated personal information in an Issue.

This code applies to Issues, Pull Requests, reviews and other project spaces maintained by this repository.
