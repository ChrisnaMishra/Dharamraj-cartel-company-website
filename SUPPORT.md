# Help and Support

## Website feedback and bugs
Please use the repository's Issue templates for:
- A broken link, missing image or visual problem.
- A feature idea or accessibility improvement.
- Feedback on the Store, construction catalogue, mobile layout or enquiry flow.

Include the page URL, device/browser and a screenshot when useful. Never include passwords, account tokens, private customer data or confidential supplier information.

## Contributing code
Read [CONTRIBUTING.md](CONTRIBUTING.md) and submit changes as a pull request targeting `development`. Do not push directly to `main`.

## Security concerns
Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

## Business enquiries
GitHub Issues are for website development only. For product prices, availability, orders or business enquiries, use the WhatsApp contact shown on the website.
