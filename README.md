# Dharamraj Cartel Website

Official website repository for Dharamraj Cartel.

## Website

- Live website: https://chrisnamishra.github.io/Dharamraj-cartel-company-website/
- `index.html` — homepage, retail Store, sourcing information, enquiry form and contact.
- `products.html` — searchable/filterable construction and hardware catalogue.

## Safe workflow

1. Fork the repository and create a feature branch in your fork.
2. Test your change in a browser.
3. Open a pull request targeting `development`, not `main`.
4. The repository owner reviews contributions before anything is merged into the public site.

Do not request write access just to contribute. Do not change the original brand artwork without approval, use unlicensed assets, post confidential data, or commit passwords, tokens, API keys, or other secrets.

## Important

This is a static site. Enquiry links prepare or open WhatsApp messages; the site does not process payments or maintain live inventory. Products shown are not a guarantee of current stock.

The repository does not yet define a project-wide software license. Do not assume public visibility grants permission to reuse the source code, trademark, logo, or photographs.
