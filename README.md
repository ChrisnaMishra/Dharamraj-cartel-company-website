# Dharamraj Cartel Website

Official website repository for Dharamraj Cartel.

## Website

- Live website (current public version): https://chrisnamishra.github.io/Dharamraj-cartel-company-website/
- Homepage and retail Store: `index.html`
- Construction and industrial product catalogue: `products.html`
- Store uses the Dharamraj Cartel bull emblem as a subtle background watermark; the original Kalash brand emblem remains part of the site's branding.

## Safe contribution workflow

1. Fork the repository.
2. Create a branch in your fork for the proposed change.
3. Test it in a browser, including a mobile viewport for visual changes.
4. Open a pull request targeting the **`development`** branch.
5. Wait for the repository owner to review it. Only owner-approved changes should be merged into `main`.

Do not request direct write access just to contribute. Do not change the original trademark artwork, add unlicensed images, publish confidential details, or commit passwords, API keys, tokens, or other secrets.

## Important notes

This is currently a static site, not a full checkout system. Enquiry buttons prepare or open WhatsApp messages; the website does not process payments or maintain live inventory.

A product image or category on the site is not a guarantee of current stock. Availability, pricing, delivery, warranties, registration details and business claims must be confirmed before they are published as facts.

The repository does not yet define a project-wide software license. Do not assume that public visibility grants permission to reuse the source code, trademark, logo, or photographs.
